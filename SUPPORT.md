# Getting help

- **Documentation** — [docs.agentsdr.ai](https://docs.agentsdr.ai): guides for
  every feature, self-hosting, configuration and integration setup (the same
  pages live in [docs/](docs/README.md)).
- **Questions and ideas** — [GitHub Discussions](https://github.com/Kandid-ai/AgentSDR/discussions).
  Search first; someone may have asked already.
- **Bugs** — [open an issue](https://github.com/Kandid-ai/AgentSDR/issues/new/choose)
  with the bug form.
- **Security problems** — never in public; see [SECURITY.md](SECURITY.md).
- **Code of conduct concerns** — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

The project is maintained by a small team. Community support is best
effort; detailed reports with steps to reproduce get answered fastest.
